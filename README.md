# 🚀 RELOAD Poster Generator (ELAD 2026)

Generador interactivo de posters oficiales para el evento **RELOAD / ELAD 2026**. Permite a los participantes crear imágenes personalizadas en alta resolución (1080x1080 px) para compartir en redes sociales de manera rápida y segura.

---

## ✨ Características Principales

- 🎨 **Filtros y Efectos Visuales Avanzados**:
  - **Composición de Imagen**: Media Imagen (*Half*), Línea Horizontal (*Eyes*) y Filtro Global (*Full*).
  - **Efectos de Color**: *RGB Glitch* (desfase cromático analógico calibrado) y *Terminal Ámbar* (con pistas de circuito interactivo).
- 🖱️ **Canvas Interactivo**: Arrastra directamente la foto sobre el lienzo o usa los controles deslizantes para ajustar escala y posición (*X/Y*).
- 📥 **Múltiples Formatos de Exportación**: Descarga en **PNG en Alta Definición** o **JPG optimizado (95%)**.
- 🔒 **100% Privacidad Local**: Todo el procesamiento se ejecuta en el navegador del usuario utilizando la API de HTML5 Canvas 2D. Ninguna imagen o dato personal es subido a servidores externos.
- 📱 **Diseño Responsivo y Temática Cyberpunk**: Desarrollado con Tailwind CSS, tipografías *Space Grotesk* y *Plus Jakarta Sans*, y paleta de colores personalizada (*Burgundy / Orange Circuit*).
- 💡 **Guía para Compartir Integrada**: Recomendaciones y hashtags oficiales (`#RELOAD #ELAD26`) accesibles en el panel y en el modal de confirmación.

---

## 🛠️ Stack Tecnológico

- **HTML5 & CSS3** (Estructura semántica, animaciones y diseño responsivo)
- **Tailwind CSS** (Utilidades de diseño modernas vía CDN)
- **Vanilla JavaScript** (Lógica de estado, manipulación de píxeles y eventos)
- **HTML5 Canvas 2D API** (Pipeline de renderizado en capas y efectos gráficos)
- **Vite** (Servidor de desarrollo local ultrarrápido)
